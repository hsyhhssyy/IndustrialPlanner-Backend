# 后端项目提交

## 能做什么

- 按 [提交执行规范](references/workflow.md) 检查根仓库和 `.docs` submodule 的改动，生成中文提交信息，并通过项目脚本完成提交。

## 不能做什么

- 不得直接执行 `git commit`，也不得绕过 `commit-all.sh`。
- 不得把用户的本地提交请求自动扩大为远端推送授权；脚本影响范围未被授权时必须先停止确认。
