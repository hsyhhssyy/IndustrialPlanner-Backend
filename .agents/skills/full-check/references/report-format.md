# 后端完整检查报告格式

使用中文报告。

## 总体结果

| 检查项 | 命令 | 结果 | 退出码 | 摘要 |
| --- | --- | --- | ---: | --- |
| Lint | `pnpm lint` | 通过 / 失败 | 退出码 | 关键摘要 |
| TypeScript | `pnpm typecheck` | 通过 / 失败 | 退出码 | 关键摘要 |
| 全量测试 | `pnpm test` | 通过 / 失败 | 退出码 | 关键摘要 |

## 失败测试

| 测试文件或模块 | 测试用例 | 失败原因摘要 | 初步分类 |
| --- | --- | --- | --- |
| 路径或 package | 用例名 | 关键错误 | 回归 / 测试漂移 / 环境 |

没有失败测试时明确写“未发现失败测试”。

## 未验证边界

列出未执行或环境无法覆盖的内容，例如：

- 缺少 Miniflare 或 `better-sqlite3`。
- 某 package 未声明 lint、typecheck 或 test 脚本。
- 远程 Cloudflare D1、KV、R2 和 Worker 未连接；这属于安全边界，不是检查缺陷。

## 工作区

说明检查前是否存在未提交改动，以及检查过程是否产生新文件。完整检查不得修改业务文件。
