# 后端 Stage 开发

## 能做什么

- 按 [Stage 开发流程](references/workflow.md) 定位 `.docs/stageN/`，读取当前需求真相层，持续同步文档、代码、测试和交接状态。

## 不能做什么

- 不得默认最新编号 Stage 就是用户要修改的范围；文档状态、用户目标或实现证据冲突时必须先收敛。
- 不得擅自提交、推送、部署或操作远程 Cloudflare 资源，也不得把归档技术栈带入当前实现。
