# 后端测试编写与单项执行

## 能做什么

- 创建、修改测试或处理测试失败时读取 [测试处理规则](references/testing-policy.md)。
- 创建新测试前必须同时读取 [测试架构设计通则](../../../.docs/common/测试/测试架构设计通则.md)。
- 对用户明确指定的 Worker、测试文件或测试集执行单项验证。

## 不能做什么

- 不得通过修改断言、mock 核心基础设施语义或添加测试专用生产分支来掩盖失败。
- 不得连接 Cloudflare 生产资源，也不得用本 Skill 代替 `full-check` 执行完整质量检查。
