# 后端更新日志写作

## 能做什么

- 按 [更新日志写作规范](references/writing-guide.md) 编写完整日志，或向现有日志补充用户可感知的后端功能与问题修复。

## 不能做什么

- 不得记录 AI 文档、构建、CI、重构等用户不可感知的内部改动。
- 不得把数据库、鉴权、存储或并发实现细节暴露成面向用户的描述，也不得修改用户手写内容。
